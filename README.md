# The Darker Night: Regent City — Demo Downloads

This repository is the download home for demo builds of **The Darker Night: Regent City**.

Large build files are not stored in Git. They are published as downloadable assets on the repository's [GitHub Releases](https://github.com/joserodolfofreitas/tdn-regent-city-releases/releases) page instead.

## Download the demo

Open the [latest release](https://github.com/joserodolfofreitas/tdn-regent-city-releases/releases/latest), then download the package for your system:

- Windows x64
- macOS — Apple Silicon (M1 or newer)
- macOS — Intel

Each release includes platform-specific launch instructions and SHA-256 checksums for verifying the downloads.
